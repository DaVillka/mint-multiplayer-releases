# MiNT Multiplayer

MiNT Multiplayer is a multiplayer platform for GTA V. Create your own servers, build custom game modes, and extend the game with scripts, interfaces, and custom content.

This repository hosts official MiNT Multiplayer releases.

[Download the latest release](https://github.com/DaVillka/mint-multiplayer-releases/releases/latest) · [Documentation](https://docs.mint-mp.com/en/) · [Release history](https://github.com/DaVillka/mint-multiplayer-releases/releases)

## Current capabilities

- **Custom servers and game modes** — run a standalone server and define your own gameplay through resources.
- **JavaScript and TypeScript** — write server and client scripts, with Node.js on the server. TypeScript is compiled to JavaScript.
- **C# server scripting** — build server resources with .NET 10, typed APIs, asynchronous handlers, and communication between C# and JavaScript resources.
- **Multiplayer synchronization** — synchronized players, vehicles, peds, and objects, with APIs for entities, events, and gameplay state.
- **Custom interfaces** — create menus, HUDs, and interactive panels with CEF or RmlUi.
- **3D previews and visual effects** — display characters, vehicles, objects, and weapons in UI scenes, and highlight entities with outlines.
- **Voice chat** — spatial voice, custom voice channels, and configurable voice effects.
- **Custom game content** — deliver and load vehicles, characters, clothing, weapons, maps, interiors, and DLC through server resources.
- **Developer tools** — JavaScript/TypeScript declarations, a C# SDK, GTA native access, an F8 console, and CEF debugging.
- **Example resources** — explore a demo with a lobby, character selection, vehicles, voice, and deathmatch modes.

## Compatibility

- **Client:** Windows x64.
- **Game:** GTA V Legacy **1.0.3889.0**, Rockstar Games Launcher edition.
- **Server:** Windows x64; Ubuntu 24.04 x64 is available as a preview.
- **C#:** server-side only.
